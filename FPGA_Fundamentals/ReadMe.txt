Digital Circuits Implementation
This repository contains VHDL code and simulation files for implementing fundamental digital circuits. These circuits are essential for understanding digital design principles and are implemented and tested using Xilinx Vivado for FPGA development.

Included Circuits
1. Basic Arithmetic Circuits
Adder: 1-bit and n-bit adders using Half and Full Adder logic.
Subtractor: 1-bit and n-bit subtractors.
Ripple Carry Adder-Subtractor: Combines addition and subtraction functionalities in one circuit.

2. Combinational Circuits
Multiplexer (MUX): N-to-1 data selector.
Demultiplexer (DEMUX): 1-to-N data distributor.
Comparator: Binary magnitude comparator for equality and inequality checks.

3. Sequential Circuits
Flip-Flops: D, T, JK, and SR flip-flops.
Counters: Synchronous and asynchronous (ripple) counters.
Shift Registers: Serial-in Serial-out (SISO), Serial-in Parallel-out (SIPO), and Parallel-in Parallel-out (PIPO).
4. Arithmetic Logic Unit (ALU)
A multi-functional circuit capable of performing arithmetic (addition, subtraction) and logical operations (AND, OR, XOR).

Tools and Technologies
HDL: VHDL for hardware description.
Simulation and Synthesis: Xilinx Vivado for functional verification and FPGA implementation.

Learning Objectives
Understand the design and implementation of fundamental digital circuits.
Explore the behavior of combinational and sequential logic.
Gain hands-on experience with simulation, debugging, and FPGA implementation.
